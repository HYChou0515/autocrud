# Quick Start - Integrate Existing Codebase

This quickstart we show how to integrate existing codebase.

## Prerequisite:

### backend
- If you are using fastapi, make sure it can be updated to at least v0.115
- If you are using pydantic, make sure it can be updated to at leaset v1.10.26, v2 is also supported.

### Frontend
If you need a frontend, make sure the following requirements is meet.
- react typescript
- mantine 7 or 8
- tanstack router
- tanstack query
- tanstack table (Mantine Rect Table)
- vite
